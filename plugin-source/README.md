# 文心

用于 SillyTavern 的摘录、文字排版、模板管理与册子拼页扩展，同时适配桌面端和手机端。

## 使用

1. 刷新 SillyTavern，点击输入框下方的魔棒按钮，再点击“文心”。
2. 在聊天正文中选中文字，会出现“保存”和“分享”。保存会将文字加入文库；分享会直接带入排版页。
3. 文库、图库、字体、模板和册子数据保存在当前浏览器的 IndexedDB 中。
4. 首次升级后会在图库中加入“内置图库”文件夹及 14 张高清图床素材；它们与普通图片一样可以移动或删除，删除后不会在刷新时自动恢复。已有内置素材会自动升级为高清地址。

## 排版操作

- 点击排版页左上角“返回”可以退出排版；齿轮面板和图层属性面板均可用右上角 × 单独关闭。
- 尚未选择纸张时切换到文库、图库、模板库或册子，会自动关闭选择纸张窗口并取消本次选择。
- 纸张可在灰色工作区中自由拖动位置；电脑端使用鼠标滚轮并以指针位置为中心缩放，手机端使用单指移动、双指捏合缩放。右下角百分比按钮可随时恢复为适应屏幕的居中视图。
- 离开普通排版页时会询问是否暂存：暂存可在切换其他板块或重新打开插件后继续编辑；不保存会清除草稿，下次进入重新选择纸张。册子页仍直接保存在对应册子中。
- 第一次点击内容会显示醒目的实体蓝色选中框，文字和图片使用完全相同的选框样式；选中后可直接拖动内容本体，也可拖动选框上沿的十字按钮移动。上沿同时提供合并、上移、下移和删除快捷按钮（图片另有裁剪），四角控制点用于调整图片或文字框尺寸，点击画布空白处取消选择。
- 选中框的“合并”按钮会进入画布点选模式，直接点击图层即可加入或移出选择，已选项目会显示明显的蓝框和勾号。手机端顶部浮动栏使用大尺寸按钮：点 `✓` 完成合并，点 `×` 取消本次合并。合并后点击任一成员都会显示整组外框，可统一移动、四角缩放或删除；外框上的“取消合并”可恢复独图层。组合信息会随模板和册子保存。
- 齿轮设置顶部可一键导入 `{{char}}`、`{{user}}`、当前日期或当前时间；每次导入都会创建一个可独立编辑的文字框。快捷文本框会保留受控的宏匹配信息，随模板 JSON 导出；其他用户导入或套用模板时，会自动匹配其当前 SillyTavern 中的角色、用户、日期和时间。
- 文字支持横排、竖排及替换优先级；从底部“模板库”可直接选择模板替换当前画布，快捷宏文本框会自动匹配当前 SillyTavern 信息。
- 文字图层提供“标题 1、标题 2、标题 3、正文”四种一键样式，会同时设置字号、字重和行高，但不会替换已选字体。手动修改字号后会自动转为自定义样式。
- 字体选择提供“跟随 SillyTavern 系统字体”，会直接使用当前主题设置的字体；字体库还内置汇文明朝、京华老宋、霞鹜文楷、朱雀仿宋四款在线字体，无需手动导入即可使用。
- 文字可启用纯色底色，也可从图库选择图片并自动创建位于文字下方的独立背景图层。
- 纸张颜色处可从图库选择背景图片，并设置裁切铺满、完整显示或拉伸以及独立透明度；编辑画布、保存前预览、PNG、模板预览和册子阅览会保持一致。纸张颜色和文本纯色底色也支持独立透明度。
- “纸张尺寸与颜色”中的“裁切画布”使用与图片裁剪相同的原图预览、可移动裁剪框和四角控制点。应用后会修改纸张尺寸、同步平移所有图层，并保留背景图在裁切前的视觉位置。
- 图片图层可从属性面板或选中框快捷按钮进入裁剪；直接在原图上拖动裁剪框或四角控制点，不使用位置、缩放拉条。
- 图片完成裁剪后仍可切换“裁切铺满、完整显示、拉伸”模式，编辑画布、册子阅览、PNG 和 PDF 会使用一致的填充结果。
- “图形”工具提供长方形、圆形、椭圆、直线和虚线，可设置填充状态、十六进制颜色码和线型；图形可自由拉宽、压窄，线条粗细使用无上限数值输入。
- “打码”会先要求输入原文字，再选择黑条、圆点或方块样式，并自动匹配当前页全部文字图层中的相同内容；进入文字编辑时仍显示原文。
- 所有颜色字段均使用 `#RRGGBB` 十六进制颜色码，填写过程中不会刷新画布；按回车或点击应用按钮后生效，同时保留调色盘。
- 图片和图形图层可相对整张纸张水平或垂直对齐；文本框的六向对齐按钮用于调整框内文字位置。选中框提供删除、上移和下移快捷按钮。
- 齿轮设置中的图层列表可直接拖动排序，列表顶部对应最上层图层。
- 图层属性支持实线、虚线、点线、双线边框，以及数值边框粗细、边框颜色和独立透明度。
- 保存模板或图片前会先生成预览，确认效果后再选择保存方式。
- 册子编辑使用多页排版工作台，可在左侧（手机端为顶部）新增、选择、排序和删除册页，每页均支持完整图层排版。
- 册子编辑器的每个册页项目都可单独“添加到模板库”，可设置模板名称、文件夹和标签；保存内容以所点击的册页为准，不要求先切换到该页。

## 册子阅览与交换

- 书架中的“阅览”会打开独立画廊界面，顶部按钮可进入或退出真正的全屏模式；移动端会随竖屏、横屏和全屏尺寸变化自动等比放大填充。画廊与排版工作台使用同一套文字、Markdown、图片裁剪及图形渲染，避免预览样式偏差。
- 书架卡片会像模板库一样生成真实画布缩略图，并固定使用册子的第一页作为封面预览；空册子显示默认占位封面。
- 画廊支持无效果、平滑、3D 仿真翻页、渐变和缩放五种动画，选择会保存到当前浏览器。可通过两侧按钮、底部真实页面缩略图、左右滑动手势或键盘方向键翻页，`Esc` 可退出阅览。
- 进入全屏后默认隐藏顶部信息栏、翻页按钮和底部缩略图，只显示正在阅览的册页；轻点页面可在纯净阅览与完整操作界面之间切换，滑动翻页不会触发界面显隐。
- 册子可导出为 `.wenxin-booklet.json`，文件包含全部册页、画布和图层；其他用户导入后会作为一本新的可编辑册子使用。
- 导入时会重新生成册子、册页和图层 ID，不会覆盖本地现有册子；分类标签不会跨用户导入。
- PDF 会先以最高 2 倍像素密度逐页栅格化，再使用无损图片压缩嵌入。PDF 中不包含可选中或可编辑的文字对象，效果相当于把高清图片逐页装订。
- 导出前会主动等待模板使用的字体载入；未安装或无法加载的外部字体仍会由浏览器使用回退字体。

## 标签分类

- 图库、模板库与册子中的文件夹、图片、模板及册子都可选填一个或多个标签，不再设置上级文件夹。
- 图库和模板库按目录层级显示：根目录只展示文件夹和未分类内容，点击文件夹后才显示其中的图片或模板；面包屑可返回根目录，也可作为拖放目标将内容移回未分类。
- 图库、模板库和册子的标签相互独立，可分别创建同名标签；旧版共享标签会自动复制到对应板块。
- 标签显示在页面顶部，可一键筛选并查看当前板块的独立使用数量；“标签管理”用于新增或删除标签，删除标签不会删除对应文件。

## 模板预览

- 模板库卡片会根据模板中的真实文字、图片和图形图层生成预览小图。
- 缩略图会在本次使用期间缓存；外链图片受跨域限制无法读取时，会显示“预览不可用”而不影响模板本身。

## 数据说明

- 模板卡片的“导出”提供图片和 JSON 两种格式：图片按模板原始尺寸生成 PNG 成品；JSON 保留可编辑图层，但不包含字体文件，只记录所选字体的名称。JSON 格式版本 2 会为快捷文本图层记录 `smartTextKind` 和 `smartTextMacro`，导入时仅解析插件支持的四类宏。
- 上传的字体和图片会保存在浏览器本地。清除站点数据会同时清除这些内容，建议定期导出模板和册子。
- 外部图片 URL 需要图片服务器允许跨域访问，才能导出为图片或 PDF；否则请改为上传图片文件。
- 文心的输入、确认和操作提示均在插件界面内显示，不使用浏览器原生提示框。
